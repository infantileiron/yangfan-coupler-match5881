# 桌面模型铁路车钩适配

项目短名 `yangfan-coupler-match`。视觉采用葡萄酒红与象牙色、铁路图册。

海岬模型铁路社 · 车钩台架组。海岬模型铁路社有 18 名会员和 1 套低速试挂台架，由 3 名轮班技师为收藏级桌面模型车厢确认换件方案。技师原先用台账筛车型和扣头，再翻历史备注核对垫片高度。上游是已试挂台账和待处理的换件计划，下游是台架轮班与换件复核。

一份 CSV 同时包含已试挂台架记录与拟试挂配置。高度差以固定参考扣头为零点，录入范围为 −2 至 +2 毫米。已试挂连续三次低速推挂均扣合且无脱钩记 1，否则记 0。待试挂结果填 -1。 输出时间留出集的交叉模型与加性模型评分，以及每条候选的台架排程、完整组合训练次数、近期参考记录和补测依据。

- 相同扣头在不同车型和安装高度上的表现差异，在按单字段筛查的台账中难以发现。
- 每次换件都重新翻历史台架记录，近期试挂结果没有独立保留用于检验判断。
- 以前未试过的完整组合也会被顺手排进优先队列，技师缺少可追踪的补测依据。

## 六个业务模块

1. 换件排程概览
2. 台架试挂簿
3. 车钩组合拟合
4. 候选配对明细
5. 试挂顺序复核
6. 轮班台架报告

6. 10:00，复核人确认当班试挂顺序，将排程报告分发给车钩台架晚班。

## 算法与复核

按已试挂记录的最近若干日留出，独立拟合带 L2 正则的加性与交叉逻辑回归。交叉模型在车型、扣头、安装高度档的独热主效应上增加三字段组合编码。−0.25 至 +0.25 毫米为平齐档，超出两端分别为偏低和偏高。对数损失越低越好。待试挂优先级使用交叉模型概率，完整组合的证据计数只取训练集。

编号重复、日期或工况无效、试挂状态与结果不符会中止运行。训练与留出样本太少、缺少通过或失败记录、训练维度只有一类时需补录或调整窗口。完整组合在训练集中缺失或记录不足时，该候选暂缓推荐并提示补测。 复核问题为「哪些配置可排在当班优先试挂，哪些必须先补测相同车型、扣头和安装高度档？」。每次分析绑定数据版本和参数，原始数据按规范化内容的 SHA-256 去重。日程针对已复核的固定结果版本，每日模式按初次投递时间每 24 小时重复。停机期间错过多次时只补一份到站内收件箱，下一次回到原时间点。

| 字段 | 含义 | 类型 |
|---|---|---|
| `record_id` | 试挂编号 | str |
| `date` | 试挂日期（YYYY-MM-DD） | str |
| `vehicle` | 车型（短轴货车、长轴客车、转向架货车） | str |
| `head` | 扣头（短柄扣、长柄扣、摆臂扣） | str |
| `offset_mm` | 安装高度差（毫米） | float |
| `stage` | 记录状态（已试挂或待试挂） | str |
| `passed` | 试挂结果（1 通过、0 失败、-1 待试挂） | int |

## 启动

```sh
[ -f .env ] || cp .env.example .env
docker compose up -d --build --wait
docker compose exec -T backend python -m scripts.seed_demo
```

- Web 界面 `http://127.0.0.1:18373`
- API 文档 `http://127.0.0.1:19373/docs`
- 数据库端口 `17873`

| 账号 | 演示密码 | 工作权限 |
|---|---|---|
| analyst | analyst-demo-24 | 导入 CSV、运行分析、导出工作稿 |
| reviewer | reviewer-demo-24 | 复核、设置和停止投递、导出 |
| viewer | viewer-demo-24 | 浏览结果、导出已批准的报告、查收投递 |

原生 HTML/CSS/JavaScript 前端与 Nginx、FastAPI、Python worker、MySQL 8.0 和 Redis 组成五服务 Compose。`backend/src/services/domain.py` 存放业务算法，`domain.json` 定义字段与验收口径，`frontend/src/pages` 为业务页面。更新任一侧源文件后，用 `docker compose up -d --build` 重建对应镜像。`backend/src/constants/enums.py` 和 `frontend/src/constants/enums.js` 定义角色及运行状态。`.env` 支持前端、API、数据库端口、演示 seed 开关和 JWT 密钥。首次部署到非演示环境时更换演示身份及 JWT/数据库凭据。

`docker compose down` 停止服务并保留数据卷。现场数据和演示结果可以在各自版本中并存。
